# Проверенные запуски

Результаты получены реальным выполнением кода на CPU. Конфигурация, версии моделей, хэш корпуса, состав выборки и окружение сохранены в `result.json` каждого варианта.

## Сравнение поиска

Размеры и перекрытия заданы в символах. Исходная конфигурация — `configs/experiment_baseline.json`: секции 1000/150, E5, Top-K=20, reranker включён. Каждый вариант меняет только указанные параметры. Для сопоставления embedding-моделей отключены reranker и порог сходства у обоих вариантов. Порог reranker сравнивается с исходными 0,05; он не является вероятностью.

Для приложения выбран `fixed_1000`: Recall 0,952 при меньшем среднем времени и более коротком контексте, чем у `fixed_1400`. Наибольший MRR у размера 1400. Это выбор по dev-данным; тестовые вопросы не участвовали в выборе.

Время поиска исключает вычисление query embeddings: они заранее рассчитаны пакетом. Первая загрузка reranker включена во время первого вопроса. Генерация и загрузка индекса в этот столбец не входят. Замеры выполнены в Linux, а не на ПК пользователя.

## Сохранённые данные и повторение

`answers.jsonl` содержит вопрос, эталонный ответ, метрики и упорядоченные идентификаторы найденных фрагментов с оценками. Повторяющиеся полные тексты корпуса исключены из опубликованной копии; они остаются в локальных `experiments/runs/`. Идентификаторы фрагментов воспроизводятся по зафиксированным документам, версиям моделей и параметрам. Оригинал ANRE проверяется по SHA-256; OCR-снимок включён в репозиторий.

Команда повторения поиска:

```powershell
.venv\Scripts\python.exe -m scada_rag experiments --suite retrieval --split dev
```

Чтобы опубликовать новую компактную копию фактического запуска:

```powershell
.venv\Scripts\python.exe scripts/export_verified.py experiments/runs/ИМЯ_ЗАПУСКА experiments/verified/НОВОЕ_ИМЯ
```

Проверка наличия цитаты в контексте не доказывает обоснованность ответа. Лексическое покрытие ключевых фраз также не заменяет ручную проверку. Ручные оценки не выставлены автоматически.

## Полный прогон генерации

На всех **42 вопросах** (36 с ответом, шесть без ответа) выполнена базовая конфигурация с Qwen 2.5 3B. Правильное решение «ответить / отказать» — **34/42 (0,810)**. На все шесть вопросов без ответа система отказала; на восьми положительных вопросах также отказала. Среднее лексическое покрытие ключевых фраз положительных вопросов — **0,685**. Все выданные ссылки принадлежали переданному контексту; это не доказывает правильность каждого утверждения.

В [generation-all/terminal-summary.json](generation-all/terminal-summary.json) сохранена фактическая сводка из вывода завершённого процесса. Полные тексты ответов этого прогона не сохранились после перезапуска среды, поэтому в опубликованной копии нет вымышленных ответов и ручных баллов. Полную запись каждого вопроса можно получить повторной командой:

```powershell
.venv\Scripts\python.exe -m scada_rag evaluate --generate --split all
```

Для сравнения двух инструкций и температур 0/0,4 предусмотрена команда `experiments --suite generation --split dev --limit 4`: seed=42, одни и те же q33, q04, q01, q39. Пробный запуск трёх вариантов завершён, но сравнительные метрики этого запуска не вошли в сохранённую сводку. Опубликованное количественное сравнение конфигураций относится к поиску, а не к качеству генерации.
